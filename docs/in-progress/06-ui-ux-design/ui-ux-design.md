# UI/UX設計書

## 1. はじめに

### 1.1 目的

本文書は、リアルタイム文字起こし翻訳 Chrome 拡張の UI / UX 設計を定義する。Popup、Side Panel、翻訳オーバーレイ、拡張専用表示タブの役割を明確にし、速度重視の体験を阻害しない画面構成と操作原則を整理する。

### 1.2 対象ユーザー

詳細な利用者像は [ペルソナ設計書](../11-persona-design/persona-design.md) を参照する。

| ユーザータイプ     | 特徴                                                     | 主な利用シーン               |
| ------------------ | -------------------------------------------------------- | ---------------------------- |
| コンテンツ視聴者   | 映像や配信を見ながら単方向翻訳を即時確認したい           | 動画視聴、ライブ配信視聴     |
| 会議参加者         | マイク入力と会議音声を見分けながら双方向翻訳を確認したい | Web 会議、通話、インタビュー |
| 複数音源モニタ担当 | 複数ソースを同時監視したい                               | 配信監視、通訳補助、実況確認 |

### 1.3 対応する基本設計

- [基本設計書 - 画面設計](../02-system-design/system-design.md#6-画面設計)

## 2. デザイン原則

1. **即時把握**: 現在の状態、最新字幕、エラーを一目で判断できること
2. **非侵襲性**: オーバーレイはコンテンツ視聴を邪魔せず、必要時にのみ主張すること
3. **ソース分離**: 複数音源が混ざらず、色・ラベル・配置で識別できること
4. **再操作容易性**: 権限拒否、翻訳失敗、再接続などの回復導線がすぐ見つかること

## 4. 画面設計

### 4.1 Popup

**画面ID:** `SCR-001`  
**対応機能:** [SD-001](../02-system-design/system-design.md#sd-001), [SD-002](../02-system-design/system-design.md#sd-002)

```text
+----------------------------------+
| Realtime Overlay                 |
| [＋ タブを追加] [＋ マイクを追加] |
|----------------------------------|
| Active Sources: 2                |
| - YouTube Live      [稼働中]     |
| - USB Mic           [翻訳停止]   |
|----------------------------------|
| [サイドパネルを開く]             |
+----------------------------------+
```

**画面仕様:**

| 要素             | 仕様                                  |
| ---------------- | ------------------------------------- |
| ソース追加ボタン | タブ / マイクを即時追加。最短操作優先 |
| Active Sources   | アクティブ数と各ソース状態を簡易表示  |
| サイドパネル導線 | 詳細管理へ遷移                        |

### 4.2 Side Panel

**画面ID:** `SCR-002`  
**対応機能:** [SD-006](../02-system-design/system-design.md#sd-006), [SD-007](../02-system-design/system-design.md#sd-007)

```text
+------------------------------------------------------+
| Sources                              [Export] [Help] |
|------------------------------------------------------|
| [YouTube Live]          en-US -> ja-JP      [稼働中] |
| partial: ...                                      ...|
| final:   ...                                      ...|
| translation: ...                                  ...|
| [設定] [停止]                                       |
|------------------------------------------------------|
| [USB Mic]                ja-JP -> en-US   [degraded] |
| [再試行] [設定] [停止]                               |
+------------------------------------------------------+
```

**画面仕様:**

| 要素         | 仕様                                     |
| ------------ | ---------------------------------------- |
| Source Card  | ソース名、言語ペア、状態、最新字幕を表示 |
| 設定ボタン   | 言語、オーバーレイ、表示先を変更         |
| 再試行ボタン | `degraded` / `error` 時のみ表示          |
| Export       | セッション単位・形式選択へ遷移           |

### 4.3 ソース設定ビュー

**画面ID:** `SCR-003`  
**対応機能:** [SD-004](../02-system-design/system-design.md#sd-004), [SD-007](../02-system-design/system-design.md#sd-007)

**画面仕様:**

| 要素           | 仕様                       |
| -------------- | -------------------------- |
| 入力言語       | 手動指定 or 自動判定切替   |
| 翻訳先言語     | 必須選択                   |
| 表示モード     | 原文のみ / 翻訳のみ / 両方 |
| 位置プリセット | 上 / 下 / 左上 / 右上      |
| 透明度         | スライダー 0.2〜1.0        |
| 表示行数       | 1〜4 行                    |

**詳細設定セクション (SCR-003-Advanced):**

折り畳み可能なセクションとして「詳細」を設ける。既定値で閉じておき、利用者が
「息継ぎで字幕が切れる」などの課題に直面した際のみ展開する。

| 要素                 | 仕様                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| 無音での文末判定時間 | スライダー 200〜1200ms、刻み 50ms、既定 600ms。ツールチップ: 「息継ぎで字幕が途切れる場合は長めに設定」 |
| 句読点感度           | トグル (on / off)、既定 on                                                                              |
| 最小発話長           | スライダー 100〜3000ms、刻み 50ms、既定 500ms                                                           |
| 翻訳の文脈保持       | セレクター 0 / 1 / 2 / 3 / 4 / 5 segment、既定 3                                                        |
| 訳文も文脈に含める   | トグル、既定 on                                                                                         |

設定変更は「次の utterance から反映」と明示する。リアルタイムに反映したい場合は
セッションを停止 → 開始する導線を追記する。

### 4.4 翻訳オーバーレイ

**画面ID:** `SCR-004`  
**対応機能:** [SD-007](../02-system-design/system-design.md#sd-007)

```text
┌────────────────────────────────────────────────────┐
│ YouTube Live                          12:03  稼働中 │
│ Original:  We are starting in five minutes.       │
│ Translate: 5分後に開始します。                    │
└────────────────────────────────────────────────────┘
```

**画面仕様:**

| 要素       | 仕様                                     |
| ---------- | ---------------------------------------- |
| ヘッダー帯 | ソース名、状態、更新時刻                 |
| 原文行     | 表示モードが両方 / 原文のとき表示        |
| 翻訳行     | 表示モードが両方 / 翻訳のとき表示        |
| 背景       | 半透明の濃色サーフェス                   |
| レイアウト | 横幅はコンテンツを妨げない範囲で自動調整 |

**連結表示ルール (v0.3.0):**

`transcript.final` の `payload.precedingSegmentId` が直前の segmentId を指す場合、
overlay は「同一発話の連鎖」として以下のルールで描画する (息継ぎ分断の視覚緩和)。

| 条件                                       | 表示挙動                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------- |
| `precedingSegmentId === null`              | 新規発話ブロックとして最上段に追加、既存行はそのまま                                   |
| `precedingSegmentId` が直前 segment と一致 | 同一ブロック内に追記 (原文行 / 翻訳行ともに連結)、区切りは `opacity 0.7` の dim 化     |
| 新 final 到着                              | 前 segment は 500ms で `opacity 1.0 → 0.7` にフェード、新 segment は `opacity 0 → 1.0` |
| `maxLines` 超過                            | 既存の `OverlayPanel.Dual-line` 仕様に従い上から flush                                 |

`translation.final.payload.contextSegmentIds` が非空の場合、翻訳行の左端に
「文脈あり」を示すインラインアイコン (`·`) を付与する (アクセシビリティ用に
`aria-label="context from N segments"` を併記)。

## 5. インタラクション設計

### 5.1 操作フロー

1. Popup からソースを追加する
2. 権限要求前に用途説明を表示する
3. Side Panel で状態と字幕を確認する
4. 必要に応じて設定変更または再試行する
5. セッション終了後にエクスポートする

### 5.2 アニメーション・トランジション

| 対象                        | アニメーション             | 時間  |
| --------------------------- | -------------------------- | ----- |
| Popup / Side Panel 初期表示 | フェード + 上方向 8px 移動 | 180ms |
| Source Card 追加            | スタッガー表示             | 160ms |
| オーバーレイ更新            | テキストクロスフェード     | 120ms |
| エラー / degraded 表示      | ステータスピル色変化       | 120ms |

## 6. レスポンシブ設計

### 6.1 ブレークポイント定義

| 名称            | 幅             | 対象デバイス     |
| --------------- | -------------- | ---------------- |
| Popup Narrow    | 〜 360px       | 拡張 Popup       |
| Panel Standard  | 361px 〜 520px | Side Panel       |
| Desktop Overlay | 1024px 〜      | タブオーバーレイ |

### 6.2 レイアウト方針

- Popup は 1 カラム固定で最短操作に寄せる
- Side Panel は縦スクロール主体で、ソースカードを積層する
- オーバーレイはタブ幅に応じて `compact` / `dual-line` を切り替える

## 7. アクセシビリティ

### 7.1 準拠基準

| 項目     | 基準        |
| -------- | ----------- |
| 準拠規格 | WCAG 2.1 AA |

### 7.2 対応方針

- すべての操作要素をキーボードで操作可能にする
- 状態変化には色だけでなくラベルも併用する
- 主要テキストは 4.5:1 以上のコントラストを確保する
- 設定フォームには明示ラベルを付与する
- 重要な状態更新は `aria-live=polite` で通知する
